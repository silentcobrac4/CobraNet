## ما هو CobraNet؟

CobraNet تطبيق أدوات شبكة مكتوب من الصفر بـ Flutter. يفحص شبكتك المحلية، يعرض الأجهزة
المتصلة بها، ويضع بين يديك الأدوات التي تحتاجها لفحص الشبكة وفهمها — كل ذلك محليًا على
جهازك، دون إرسال أي بيانات إلى خادم تابع لنا.

التطبيق لا يحتوي على إعلانات، ولا على حسابات، ولا على تحليلات. الاستعلامات التي تحتاج
إنترنت (مثل WHOIS وفحص الروابط واختبار السرعة) تذهب مباشرة إلى الخادم الذي تطلبه.

## المزايا

### فحص الشبكة
- فحص كامل للشبكة المحلية (Subnet sweep) مع اكتشاف الأجهزة المتصلة.
- عرض عنوان IP، عنوان MAC، اسم الجهاز، زمن الاستجابة، والمنافذ المفتوحة.
- تخمين نوع الجهاز (راوتر، هاتف، حاسوب، طابعة، كاميرا، تلفاز، خادم…) عبر اسم الجهاز ومنافذه.
- تمييز جهازك الحالي والبوابة (Router) تلقائيًا.
- تسمية الأجهزة بأسماء مخصّصة، إضافة ملاحظات، وحفظها في المفضلة.
- فحص عميق اختياري، والتحكم في المهلة وعدد الطلبات المتزامنة.

### الأدوات
| الأداة | الوصف |
| --- | --- |
| **Ping** | قياس زمن الاستجابة وفقدان الحزم، مع بديل TCP عند تعذّر ICMP. |
| **فحص المنافذ** | مجموعات جاهزة (شائعة، ويب، منزلية، شبكة) أو نطاق مخصّص. |
| **DNS** | استعلام مباشر عن A و AAAA و CNAME و MX و TXT و NS و PTR و SOA، مع خادم مخصّص. |
| **WHOIS** | بيانات تسجيل النطاقات وعناوين IP من خوادم WHOIS العامة. |
| **تتبع المسار** | عرض القفزات حتى الوجهة مع أزمنة الاستجابة. |
| **Wake-on-LAN** | إرسال الحزمة السحرية لتشغيل جهاز يدعم WoL. |
| **حاسبة الشبكة** | حساب القناع والنطاق والبث وعدد الأجهزة لأي CIDR. |
| **اختبار السرعة** | قياس سرعة التنزيل من خادم عام (تنزيل فقط، بلا رفع بيانات عنك). |
| **فحص الروابط** | رمز الحالة، التحويلات، الترويسات، وزمن الاستجابة لأي URL. |
| **اكتشاف الأجهزة (mDNS/Bonjour)** | ✅ | ✅ | **جديد** |
| **تحديد الشركة المصنّعة (OUI)** | ✅ | ✅ | **جديد** |
| **فحص نطاق IP مخصّص** | ✅ | ✅ | **جديد** |
| **تصدير CSV** | — | ✅ | **جديد** |

### التطبيق
- واجهة عربية بالكامل مع دعم RTL، وواجهة إنجليزية، وتبديل فوري للغة.
- سمة داكنة وفاتحة، أو اتباع إعدادات النظام.
- سجل لكل عملية تشغّلها، مع تصفية حسب الأداة وعرض التفاصيل ونسخها.
- نسخ احتياطي واستيراد كامل للبيانات بصيغة JSON.
- لا يحتاج تسجيل دخول، ويعمل دون اتصال باستثناء الأدوات التي تحتاج إنترنت بطبيعتها.

## الخصوصية

- **لا إعلانات، لا تتبّع، لا تحليلات، لا حسابات.**
- كل الأجهزة المسجّلة والسجل والإعدادات تُخزَّن محليًا في `SharedPreferences` على جهازك.
- التطبيق لا يملك خادمًا ولا يرسل أي تقرير عنه.
- صلاحية الموقع تُستخدم فقط لقراءة معلومات Wi-Fi (SSID، البوابة، القناع) على أندرويد،
  ولا يُستخدم موقعك الجغرافي لأي غرض آخر.

## التثبيت من GitHub Actions (بدون بناء محلي)

المشروع يأتي مع سير عمل جاهز يبني ملف APK تلقائيًا على GitHub.

1. أنشئ مستودعًا جديدًا على GitHub (يمكن أن يكون خاصًا أو عامًا).
2. ارفع **محتويات** مجلد المشروع إلى المستودع، مع التأكد من وجود
   `.github/workflows/build-apk.yml` في المسار الصحيح.
3. افتح تبويب **Actions** في المستودع، اختر **Build CobraNet APK**، ثم **Run workflow**.
4. بعد انتهاء البناء (حوالي 5–10 دقائق)، نزّل الملف من قسم **Artifacts** باسم
   `CobraNet-APK`، وفك ضغطه لتحصل على `app-release.apk`.
5. انقل الملف إلى هاتفك وثبّته (فعّل «تثبيت من مصادر غير معروفة» إن طُلب منك).

لإنشاء إصدار تلقائي على GitHub: أنشئ وسمًا يبدأ بحرف `v` وادفعه، مثل:

```bash
git tag v1.0.0
git push origin v1.0.0
```

سيُنشئ سير العمل إصدارًا (Release) ويُرفق ملف APK به.

## البناء محليًا

### المتطلبات
- Flutter **3.50.0** (Dart 3.14)
- JDK **17**
- Android SDK مع:
  - `platforms;android-37`
  - `build-tools;37.0.0`
  - `ndk;28.2.13676358`

### الخطوات

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

يظهر الناتج في:

```
build/app/outputs/flutter-apk/app-release.apk
```

للتشغيل على جهاز موصول أو محاكي:

```bash
flutter run
```

> ملاحظة: نسخة الإصدار في هذا المشروع موقّعة بمفتاح التصحيح (debug key) حتى تعمل
> بسهولة بعد التحميل من Actions. لنشر التطبيق على Google Play، أضف `keystore` خاصًا بك
> في `android/app/build.gradle.kts` واستخدم `signingConfig` الخاص بك.

### ملاحظات تقنية

- يستخدم المشروع `material_ui` و`cupertino_ui` بدل `package:flutter/material.dart`
  لأن Flutter 3.50 بدأ بإهمال مكتبة Material المدمجة.
- تم تثبيت `path_provider_android` و`shared_preferences_android` على آخر إصدارات لا
  تعتمد على إضافة JNI، لتجنّب اشتراط NDK أحدث على بيئات البناء.
- تم تعطيل Lint الخاص بـ Gradle في بناء الإصدار بسبب خطأ في AGP 9.3.1 عند العمل مع
  JDK 17؛ التحليل والاختبارات يتمّان عبر `flutter analyze` و`flutter test`.

## الصلاحيات ولماذا؟

| الصلاحية | السبب |
| --- | --- |
| `INTERNET` | فحص المنافذ، DNS، WHOIS، السرعة، فحص الروابط |
| `ACCESS_NETWORK_STATE` | معرفة نوع الاتصال وحالته |
| `ACCESS_WIFI_STATE` | قراءة SSID وعنوان البوابة والقناع |
| `CHANGE_WIFI_MULTICAST_STATE` | دعم اكتشاف الأجهزة عبر Multicast عند الحاجة |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | مطلوبة من أندرويد لقراءة تفاصيل Wi-Fi |
| `NEARBY_WIFI_DEVICES` | بديل حديث لقراءة معلومات Wi-Fi على أندرويد 13+ |

## قيود معروفة

- على أندرويد 10+ قد يمنع النظام قراءة جدول ARP، لذا قد يظهر عنوان MAC كـ `—` لبعض الأجهزة.
- Ping يستخدم ICMP عند توفّره، وإلا يتحول تلقائيًا إلى فحص TCP.
- تتبع المسار قد يعتمد على UDP/ICMP، وبعض الشبكات تحجب الردود؛ قد تظهر قفزات بلا رد.
- Wake-on-LAN يعمل فقط داخل نفس الشبكة المحلية وبعد تفعيله على الجهاز الهدف.
- اختبار السرعة يقيس التنزيل فقط ولا يقيس الرفع.
- WHOIS يستعلم `whois.iana.org` أولًا ثم الخادم المسؤول عن النطاق.
